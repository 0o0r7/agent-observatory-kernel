# Security Policy

Security for all AgentObservatory repositories is handled centrally:

> https://github.com/0o0r7/agent-observatory/blob/main/SECURITY.md

## Reporting a vulnerability

Please use the central repository's GitHub Security Advisories
("Report a vulnerability" under the **Security** tab of
https://github.com/0o0r7/agent-observatory). Do **not** open public issues for security-sensitive findings.
